    What is happening here?

    1. Cut the text into tokens

    Your text is split into small pieces called tokens. Here a token is a word or a punctuation mark. Real LLMs use pieces of words, for example un + believ + able.

    2. Count what comes next

    For every run of words in your text, the model remembers which word came next. If you set memory to 2 words, it asks: "After the old, what did I see?" Maybe man 5 times and house 2 times.

    3. Turn counts into probabilities

    5 out of 7 is about 71%, so man has a 71% chance and house has a 29% chance. This is a probability distribution over the next token.

    4. Roll the dice, then repeat

    The model picks one word at random using those chances. Then it adds that word to the text and does it again. One word at a time, a reply appears. Real LLMs work the same way.

    What if it has never seen this?

    If it never saw your exact words, it backs off: it forgets the oldest word and tries again with fewer words. Click a word in a reply to see how many words of memory it used.

    So how is ChatGPT different?

    This model can only repeat patterns it saw exactly. A real LLM is a neural network with billions of learned numbers. It reads thousands of tokens of context, not 6. It learns meaning, so it can guess well for sentences it never saw. It is also trained on a large part of the internet, and then taught to be a helpful assistant. But the basic job is the same: predict the next token.

    Technical note: this is a word-level n-gram model with "stupid backoff". It is built on a suffix array of your text, so any memory length from 1 to 6 works without rebuilding. Everything runs in your browser.
